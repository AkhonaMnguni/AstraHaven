# OWASP Mapping

- A01 Broken Access Control: blueprint login checks and `roles_required`.
- A02 Cryptographic Failures: hashed passwords; use TLS and secret management in production.
- A03 Injection: SQLAlchemy query APIs and parameterized ORM operations.
- A04 Insecure Design: threat model and least-privilege roles.
- A07 Identification and Authentication Failures: Flask-Login session boundary.
- A09 Security Logging and Monitoring Failures: audit logger baseline.
