# Requirements

AstraHaven provides authenticated users with a small-business risk console for reviewing transactions, suppliers, alerts, and user access.

## Roles

- `admin`: full access, including user administration.
- `analyst`: review and resolve financial alerts.
- `viewer`: read-only access.

## Baseline capabilities

- Password-based sign-in and sign-out.
- Transaction and supplier views.
- High-value transaction detection.
- Alert review and resolution.
- Audit logging for key actions.
